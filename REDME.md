# 🚗 Parking Lot Management API

A simple *REST API* built with *Node.js, Express, and MongoDB* to manage parking lots.  
You can *add, view, update, and delete* parking lot records.

---

## ⚙ Tech Stack
- Node.js
- Express.js
- MongoDB + Mongoose
- Postman (for API testing)

---
